Watchlist formats
  • CSV with a header. Columns: code (or isin / secid / ticker) — ISIN or MOEX code; name — the bond name as MOEX and cbonds write it, "issuer, series", e.g. АФК Система, 001P-06 — if code is empty, the ISIN is looked up by name (and maturity date, if given); matdate — maturity date, helps find the right bond by name; qty — how many bonds you hold, to compute totals. Only one of code or name is required; Russian column names (as in cbonds exports) work too.
  • Plain text: one bond per line, optionally followed by a quantity. Anything after # is a comment.
  • Both ISINs (RU000A1038V6) and MOEX codes (SU26238RMFS4) work. Matured bonds MOEX no longer lists get the code - so they aren't looked up again.
