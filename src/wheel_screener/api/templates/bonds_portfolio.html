Import a portfolio report
Replaces what this portfolio holds with the bonds in the file — import a newer report to bring the portfolio up to date.
  • Intelinvest portfolio report (complex_portfolio_report_….xlsx): the bonds on its «Портфель облигаций» sheet — «Тикер» (ISIN), «Название» and «Количество, шт.». Bonds sold out (a quantity of 0) are left out. Maturity dates are taken from MOEX.
  • Another spreadsheet (.xlsx) or a CSV with a header row: code (or isin / secid / ticker / тикер) — ISIN or MOEX code; name (or название) — the bond name as MOEX and cbonds write it, e.g. АФК Система, 001P-06, looked up when there is no code; matdate — the maturity date, which helps find a bond by name; qty (or количество) — how many you hold. The CSV download above is this format, so a portfolio can be edited in a spreadsheet and imported back. CSV may be UTF-8 or Windows-1251.
  • Plain text: one bond per line, its ISIN or MOEX code and then the quantity. Anything after # is a comment.
